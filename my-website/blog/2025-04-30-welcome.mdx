### Intro

Hi, I'm Justin. I'm an engineer and I'm on a mission.

### The mission

To **think** and **do** through code and through writing.

I built this website using [Docusaurus](https://docusaurus.io/).

The website is hosted on [GitHub](https://github.com) via GitHub Pages.

Docusaurus helped me scaffold up a usable blog/docs website that does _not_ prelcude me from tinkering with the coding stuff I also want to get into. GitHub and GitHub Pages allows me to host the site for free. The only thing I actually pay for is the custom domain name.

Docusaurus is a slight deviation from my original intent of building every single thing from scratch using [Angular](https://angular.dev/) which I do like, and play with for other needs. Docusaurus is built on [React](https://react.dev/) which is not completely foreign to me, but something new.

Over time you will see new things coming out on the site that is the result of my tinkering with code, so stand by. Otherwise, you will see my writing coming out quicker because I'm not building any of that for myself.

I started using [Obsidian](https://obsidian.md/) a long time ago and it taught me to use [Markdown](https://en.wikipedia.org/wiki/Markdown) and I learned to love it. I wanted a way to write my blog posts in Markdown format and right in my [IDE](https://vscode.dev/).

But long before Obsidian, I had built a website on Wordpress, but I really didn't like it, customizing it didn't allow me to flex my coding muscles the way I wanted to. This allows me to.
